# Anti Shooter — GMTK Game Jam 2018

A space arcade game made with Unreal Engine 4 for GMTK Game Jam 2018.

![Anti Shooter gameplay](Anti_Shooter/Screenshots/Anti%20Shooter.jpg)

## Playing

The included build targets **64-bit Windows**. With a complete copy of the game, launch `Anti_Shooter/Game/Anti_Shooter3.exe`, keeping the surrounding folders intact. If required, install the bundled prerequisites from `Anti_Shooter/Game/Engine/Extras/Redist/en-us/UE4PrereqSetup_x64.exe`.

**Archive note:** This checkout contains executables and engine dependencies, but no packaged game content (`Content/Paks`). A complete build is needed to play. Unreal Engine project source is not included.
